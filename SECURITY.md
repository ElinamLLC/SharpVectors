# Security Policy

## Supported Versions

Security fixes are intended for the latest released version of SharpVectors. Older releases may not receive security updates. Please update to the latest release when possible.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately rather than opening a public issue. Use the **Report a vulnerability** button on the [Security Advisories page](https://github.com/ElinamLLC/SharpVectors/security/advisories). This option requires a GitHub account.

Please include, where possible:

- The affected SharpVectors version and runtime environment.
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue and a minimal proof of concept.
- Any relevant configuration or mitigations.

The maintainers will review the report and communicate with you through GitHub. Please allow time for investigation and coordinated disclosure before sharing details publicly. Response and resolution times may vary depending on the complexity of the report and maintainer availability.
